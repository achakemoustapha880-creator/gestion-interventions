# Gestion des interventions

Application web de gestion des interventions techniques.

## Présentation

Cette application permet de faciliter le suivi et la gestion des interventions techniques.

## Fonctionnalités principales

* Gestion des clients
* Gestion des équipements
* Création des interventions
* Suivi des interventions
* Gestion des techniciens
* Historique des interventions
* Tableau de bord

## Technologies utilisées

* PHP
* Laravel
* MySQL
* HTML
* CSS
* Bootstrap

## Installation

1. Cloner le projet.
2. Installer les dépendances avec `composer install`.
3. Copier `.env.example` vers `.env`.
4. Configurer la base de données.
5. Générer la clé avec `php artisan key:generate`.
6. Exécuter les migrations avec `php artisan migrate`.
7. Lancer le serveur avec `php artisan serve`.
